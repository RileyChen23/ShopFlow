## 已实现

- 暖白、橙色主操作、浅黄提示、少量粉色；保留语义红/绿及键盘焦点。
- 维护页去除采购侧栏和偏好按钮，提供返回工作台导航。
- 运行记录按当前会话最近 100 条独立运行/操作筛选；10 条分页；窄屏紧凑行。筛选同步更新计数和有效耗时中位数。
- 中文结构化请求、结果、真实步骤、商品依据、错误、配置及费用；未知与零值分开，原始记录通过会话鉴权下载。
- 从历史逐案例记录计算堆叠条、改善/退步与百分点；默认保留验证集。不同 ID、模式、模型、资料、分组、缺失身份或未运行时停止总体比较。
- 案例详情展示保存的真实输出、断言或未记录状态；报告、数据、配置及实现仅通过明确白名单下载。
- 未修改历史评测报告，未运行模型评测或 Shopify 交易。
